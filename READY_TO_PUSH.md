4. Click "Push origin" button

**Solution 2: Personal Access Token**
1. Go to: https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Note: "Thread & Bloom Push Token"
4. Select scope: ✅ `repo` (full control)
5. Generate and copy token
6. Run: `git push -u origin main`
7. Username: `shraygupta8010-coder`
8. Password: `[paste your token]`

**Solution 3: SSH Key (Advanced)**
1. Generate SSH key: `ssh-keygen -t ed25519 -C "your_email@example.com"`
2. Add to GitHub: https://github.com/settings/keys
3. Change remote: `git remote set-url origin git@github.com:shraygupta8010-coder/thread-and-bloom.git`
4. Push: `git push -u origin main`

### Error: "Repository not found"

**Solution:**

- Repository name must be exactly: `thread-and-bloom`
- Must be under your account: `shraygupta8010-coder`
