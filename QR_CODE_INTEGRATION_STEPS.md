# Razorpay QR Code Integration - Thread & Bloom

## 🎯 Steps to Get Your QR Code:

### Step 1: Create QR Code in Razorpay Dashboard

1. Login to Razorpay Dashboard: https://dashboard.razorpay.com/
2. Go to: **Payments** → **QR Codes** (left sidebar)
3. Click: **Create QR Code** button
4. Select: **Multiple Payments** (reusable QR)
5. (Optional) Add description: "Thread & Bloom - Luxury Bedding"
6. Click: **Create QR Code**
7. Download the QR Code image

### Step 2: Save QR Code Image

Save the downloaded QR code as:
```
d:\bedsheet\public\qr-code-payment.png
```

### Step 3: Get Your UPI ID

Your Razorpay QR code will have a UPI ID like:
```
razorpay.xxxxx@icici
```

You can also use your personal UPI ID if you prefer:
```
8010890085@paytm
or
8010890085@ybl (Google Pay)
or
8010890085@paytm (Paytm)
```
