# ⚡ Quick Start Guide

Get **LuxeBed & Bath** running in 3 simple steps!

---

## 🚀 Start the Application

### Step 1: Install Dependencies
```bash
npm install
```

### Step 2: Run Development Server
```bash
npm run dev
```

### Step 3: Open Your Browser
Navigate to: **http://localhost:3000**

---

## 🎯 What to Try First

### 1. Browse Products
- **Homepage** → See hero section and featured products
- **Click "Shop Collection"** → View full catalog
- **Apply filters** → Try filtering by category, price, size

### 2. Add to Cart
- **Hover over any product** → Click "Quick View" or "Add to Cart"
- **Select size and color** in Quick View modal
- **Click cart icon** in header → View your cart

### 3. Use Promo Codes
In the cart drawer, try these coupon codes:
- `LUXE10` → 10% off
- `SAVE15` → 15% off
- `WELCOME20` → 20% off

### 4. Complete Checkout
- **Click "Proceed to Checkout"**
- **Create an account** (use any email/password)
- **Enter delivery address**
- **Select payment method**
- **Place order** → See confirmation!

---

## 💡 Pro Tips

- **Cart persists** → Refresh the page, your items stay!
- **Free shipping** → Add $50+ to cart for free shipping
- **Mobile menu** → Click hamburger icon on mobile
- **Quick filters** → Use category tabs on shop page
- **Sort products** → Try different sorting options

---

## 🛠️ Build for Production

```bash
# Create production build
npm run build

# Start production server
npm start
```
