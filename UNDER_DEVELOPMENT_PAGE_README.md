## 🔧 Customization Guide

### Update Contact Email
```html
<!-- Find and replace: -->
<a href="mailto:support@threadandbloom.com">support@threadandbloom.com</a>

<!-- Change to your actual email -->
```

### Update Business Address
```html
<!-- Find in footer section: -->
<p>
    Thread and Bloom Private Limited<br>
    123 Commerce Street, MG Road<br>
    Bengaluru, Karnataka 560001<br>
    India
</p>

<!-- Update with your actual address -->
```

### Update Phone Number
```html
<!-- Find: -->
<span>+91 (800) 123-4567</span>

<!-- Change to your actual number -->
```

### Change Colors

**Premium Version:**
```css
/* Main gradient (purple theme) */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* Change to blue theme: */
background: linear-gradient(135deg, #3498db 0%, #2980b9 100%);

/* Change to green theme: */
background: linear-gradient(135deg, #11998e 0%, #38ef7d 100%);
```

**Simple Version:**
```css
/* Header background */
background-color: #2c3e50;

/* Change to any color: */
background-color: #34495e; /* Dark grey */
background-color: #2980b9; /* Blue */
background-color: #27ae60; /* Green */
```

### Add Logo Image

Replace the placeholder with actual logo:

```html
<!-- Find: -->
<div class="logo-placeholder">
    T&B
</div>

<!-- Replace with: -->
<img src="your-logo.png" alt="Thread and Bloom Logo" style="width: 120px; height: auto;">
```
